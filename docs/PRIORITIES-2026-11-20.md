# أولويات Your Way — ٢٠ نوفمبر ٢٠٢٦

هذه متابعة للمنصة التعليمية وحدها. لا تغييرات على الموقع الشخصي أو ملف GitHub ضمن هذه المهمة.

| الترتيب | البند | الحالة والخطوة المطلوبة |
| --- | --- | --- |
| ١ | استقرار الاستضافة وأخطاء 503 | السبب السابق المؤكد تجاوز CPU عند 10ms. يلزم تأكيد خطة Cloudflare الفعلية وموافقة تكلفة أي ترقية قبل ضبط حد المعالجة وإعادة اختبار الأدوار والدفع والشكاوى تحت التتبع. نجاح صفحة اليوم وحده لا يغلق البند. |
| ٢ | استعادة كلمة المرور بالبريد | يجري نشر تحسين التحقق من الرابط والنماذج والرسائل. إغلاق البند يتطلب وصول البريد عمليًا، صحة نطاق العودة، تغيير المستخدم لكلمته بصورة خاصة ونجاح الدخول. إرسال البريد لجميع الطلاب يحتاج SMTP مناسبًا؛ اختبار بريد صاحب المشروع لا يثبت ذلك. |
| ٣ | اعتماد بيانات النشاط والسياسات ثم مراجعة PayTabs | مسودات الصفحات موجودة. يلزم اعتماد البلد والهوية القانونية والعنوان والتواصل والاسترجاع والإلغاء والتأجيل ومدة مراجعة CliQ ووصف الخدمة؛ بعدها تستكمل وثائق التاجر وفق طلب PayTabs. يبقى الدفع تجريبيًا حتى الموافقة. |
| ٤ | حماية فيديو Bunny برمز مشاهدة | مؤجلة بطلب المستخدم، ومفتاح BUNNY_TOKEN_AUTH_KEY غير مضاف وقت المراجعة. يلزم توفر المكتبة/الرصيد وتفعيل الإعداد بالتنسيق مع النشر حتى لا تتوقف المشاهدة. لا يُشترى اشتراك أو رصيد تلقائيًا. |
| ٥ | تحقق ما قبل الإطلاق | تجربة استعادة نسخة احتياطية، ومراقبة الأعطال، وتجهيز المحتوى الحقيقي والحسابات المخصصة للمراجعة وفصل التجارب عن الإنتاج، ثم إعادة اختبار شامل بعد حسم الاستضافة والبريد. هذه متطلبات جاهزية، وليست أعطالًا جديدة مثبتة. |

ميزة منع كلمات المرور المسرّبة تبقى اختيارية مؤجلة، وتحتاج خطة Supabase المناسبة وموافقة التكلفة. بريد دعم Gmail الحالي رابط تواصل فقط؛ يلزم التأكد من مراقبته ولا يغني عن SMTP.

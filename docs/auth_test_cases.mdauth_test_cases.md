أولاً: حالات اختبار صفحة التسجيل (Registration Test Cases)
TC-REG-01: التسجيل ببيانات صحيحة وصالحة

طريقة التنفيذ: إدخال بريد إلكتروني جديد وصحيح، ثم إدخال كلمة مرور قوية تطابق شروط الأمان، وأخيراً الضغط على زر التسجيل (Register).

النتيجة المتوقعة: يتم إنشاء الحساب بنجاح، ويتم توجيه المستخدم إلى صفحة التحقق أو لوحة التحكم مع ظهور رسالة نجاح واضحة.

TC-REG-02: ترك الحقول فارغة

طريقة التنفيذ: إبقاء حقول البريد الإلكتروني وكلمة المرور فارغين تماماً، والضغط على زر التسجيل (Register).

النتيجة المتوقعة: يتم منع إرسال النموذج، وتظهر رسائل تنبيه وخطأ تحت كل حقل تطالب المستخدم بإدخال البيانات المطلوبة.

TC-REG-03: استخدام بريد إلكتروني مسجل مسبقاً

طريقة التنفيذ: إدخال بريد إلكتروني مستخدم بالفعل ومسجل في النظام مسبقاً، مع إدخال كلمة مرور صحيحة، ثم الضغط على زر التسجيل.

النتيجة المتوقعة: يتم رفض عملية التسجيل، وتظهر رسالة خطأ واضحة تفيد بأن البريد الإلكتروني مستخدم بالفعل.

TC-REG-04: صيغة بريد إلكتروني خاطئة

طريقة التنفيذ: إدخال بريد غير صالح (لا يحتوي على نطاق صحيح أو رمز الـ @)، ثم إدخال كلمة المرور والضغط على زر التسجيل.

النتيجة المتوقعة: يتم منع إرسال النموذج وظهور رسالة تنبيه تطالب بكتابة بريد إلكتروني صحيح ومكتمل.

TC-REG-05: كلمة مرور ضعيفة أو قصيرة

طريقة التنفيذ: إدخال بريد صالح، ولكن إدخال كلمة مرور قصيرة جداً (أقل من الطول المطلوب أو لا تتوافق مع الشروط المعيارية)، ثم الضغط على زر التسجيل.

النتيجة المتوقعة: يتم رفض التسجيل وإظهار خطأ يوضح الشروط الواجب توفرها في كلمة المرور (مثل الطول الأدنى واستخدام رموز وأحرف).

ثانياً: حالات اختبار صفحة تسجيل الدخول (Login Test Cases)
TC-LOG-01: تسجيل الدخول ببيانات صحيحة

طريقة التنفيذ: إدخال بريد إلكتروني مسجل وصحيح، وإدخال كلمة المرور الصحيحة الخاصة به، ثم الضغط على زر تسجيل الدخول (Login).

النتيجة المتوقعة: يتم تسجيل الدخول بنجاح وتوجيه المستخدم بسلاسة إلى الصفحة الرئيسية أو لوحة التحكم الخاصة به.

TC-LOG-02: كلمة مرور خاطئة

طريقة التنفيذ: إدخال بريد إلكتروني صحيح ومسجل، ولكن كتابة كلمة مرور خاطئة غير مطابقة، ثم الضغط على زر تسجيل الدخول.

النتيجة المتوقعة: يتم منع الدخول وإظهار رسالة خطأ عامة لأسباب أمنية (مثل: "البريد الإلكتروني أو كلمة المرور غير صحيحة").

TC-LOG-03: بريد إلكتروني غير مسجل

طريقة التنفيذ: إدخال بريد إلكتروني غير موجود نهائياً في قاعدة البيانات، مع إدخال أي كلمة مرور، ثم الضغط على زر تسجيل الدخول.

النتيجة المتوقعة: يتم منع الدخول وظهور رسالة تفيد بفشل عملية المصادقة لأسباب أمنية لمنع تخمين الحسابات.

TC-LOG-04: ترك الحقول فارغة

طريقة التنفيذ: ترك حقل البريد الإلكتروني وحقل كلمة المرور فارغين، والضغط على زر تسجيل الدخول.

النتيجة المتوقعة: يتم إظهار تنبيهات التحقق البرمجية التي تمنع الإرسال وتطالب بضرورة تعبئة الحقول المطلوبة قبل المتابعة.

ثالثاً: حالات اختبار إضافية (UX & Security Test Cases)
TC-SEC-01: زر إظهار/إخفاء كلمة المرور (Show/Hide Password)

طريقة التنفيذ: كتابة نص داخل حقل كلمة المرور، ثم النقر على أيقونة العين المخصصة لإظهار كلمة المرور، ثم النقر عليها مرة أخرى لإخفائها.

النتيجة المتوقعة: تتحول الحروف إلى نص مرئي واضح للمستخدم عند الضغط على إظهار، وتعود لتصبح مخفية (على شكل نقاط) عند إعادة النقر.

TC-SEC-02: حماية الحقول من هجمات الحقن (XSS)

طريقة التنفيذ: محاولة إدخال سكريبت برمجي خبيث (مثل وسم سكريبت تجريبي) داخل حقل البريد الإلكتروني أو حقل اسم المستخدم، ثم محاولة الإرسال.

النتيجة المتوقعة: يقوم النظام بتنظيف المدخلات (Sanitization) أو ترميزها برمجياً بحيث لا يتم تنفيذ الكود كسكريبت خبيث داخل متصفح المستخدم.

TC-NAV-01: إعادة تعيين كلمة المرور (Forgot Password)

طريقة التنفيذ: النقر على رابط أو زر "هل نسيت كلمة المرور؟"، ثم إدخال البريد الإلكتروني المسجل والنقر على زر إرسال رابط الاستعادة.

النتيجة المتوقعة: ينتقل المستخدم إلى صفحة استعادة كلمة المرور بنجاح، ويتم إرسال رابط التحقق أو تظهر رسالة نجاح الإرسال على الشاشة.

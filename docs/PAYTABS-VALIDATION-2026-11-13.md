# التحقق من تجهيز صفحات الدفع والسياسات

التاريخ: ١٣ نوفمبر ٢٠٢٦ بتوقيت عمّان.

## النطاق

صفحات المعلومات العامة، مسودات السياسات بالعربية والإنجليزية، روابط أسفل الموقع والدفع، البريد المقترح، ومعاينة الموافقة غير المفعّلة. لا توجد تعديلات لقاعدة البيانات أو مفاتيح خدمات أو منطق اعتماد عمليات الدفع. لا توجد طلبات شراء أو اشتراكات مدفوعة جديدة ضمن هذا العمل.

## النتائج المحلية

- نجح ١٧٢ اختبار وحدة وانحدار، بما فيها اختبارات استعادة الدفع والتحقق منه، و٨ اختبارات جديدة للمحتوى والروابط وحالة المسودة وفصل معاينة الموافقة عن الدفع.
- نجح فحص الأنواع.
- فحص جودة الكود: صفر أخطاء، و١٠ تنبيهات سابقة تخص الصور والخطوط؛ لا تنبيهات جديدة.
- فحص الحزم: صفر ثغرات معروفة حسب نتيجة الفحص وقت التنفيذ.
- نجح بناء Next.js الإنتاجي وبناء Vinext المستخدم للاستضافة.
- متصفح Chromium: ٧٢ حالة عرض = ٦ صفحات × لغتين × ٣ مظاهر × عرضي شاشة ٣٩٠ و١٤٤٠. جميعها استجابت برمز ٢٠٠، دون خروج أفقي للمحتوى أو أخطاء جافاسكربت مكتشفة.
- فحص إتاحة آلي لصفحة الخصوصية في ١٢ تركيبة من اللغات والمظاهر والأحجام: لم تُكتشف مخالفات ضمن قواعد WCAG A/AA و٢٫١ AA المفعّلة. هذا فحص آلي لعينة ولا يثبت توافقًا شاملًا لجميع الحالات.
- اختبار عملي لتبديل اللغة والمظهر واستمرارهما بعد إعادة التحميل.
- اختبار نسخة الإنتاج محليًا: الصفحات الست ومعاينة الموافقة على عرض ٣٢٠، ثم الصفحة الرئيسية والكتالوج وروابط التذييل. ظهر تذييل واحد مرئي، واستمرت اللغة والمظهر عند الانتقال إلى سياسة الاسترجاع.
- تأكيد أن روابط الدفع تفتح السياسات بتبويب جديد، وأن المعاينة معطّلة ولا تنشئ موافقة أو شرطًا إلزاميًا للشراء.
- طلب عدم الفهرسة موجود في صفحات المعلومات والمسودات. عدم الفهرسة لا يُعد حماية وصول أو ضمانًا لإزالة الصفحة من محركات البحث.

## الحدود وما بقي

هذه نتائج النسخة المحلية، وليست تأكيد نشر. اتصال GitHub الموجود أعاد رفض بيانات الاعتماد، وبالتالي يتطلب الرفع والنشر تجديد الاتصال ثم اجتياز فحوصات المستودع والتحقق من الموقع المنشور. تمت مطابقة الفرع الأساسي مع الفرع البعيد قبل حفظ التعديلات.

لم يتم اختبار وصول رسائل البريد، ولا إرسال طلب تاجر، ولا تفعيل دفع حي. الشروط والاسترجاع والخصوصية وتقديم الخدمة مسودات وتحتاج اعتمادًا قبل تقديمها كسياسات نهائية. التفاصيل المطلوبة والمؤجلات في [قائمة الجاهزية](PAYTABS-READINESS.md).

# قائمة متابعة فحص الجودة

المتابعة الحالية لتدقيق ١١ تشرين الثاني ٢٠٢٦: أُنجز البند الأول سابقًا، وتغطي الجولة الثانية البنود ٢ و٤ و٥. أُجّل البند ٣ بطلب المستخدم.

- [x] **١. تم في الكود والاختبارات: سحب صلاحية إدارة الدورة فور تغيير دور المعلم.** يشترط الحارس الدور الحالي؛ التعيين القديم لا يمنح طالبًا أو مديرًا محدودًا صلاحية التعديل أو تجهيز رفع فيديو. تشمل إعادة الاختبار بقاء الجلسة والتعيين، والحسابات المسموح لها، وفشل استعلامات التحقق.
- [x] **٢. تم في الكود والاختبارات: إصلاح تحرير درس باني عند المعلم والمدير.** تستعيد الواجهة المشتركة المزوّد ومعرّفات باني ومكس ويوتيوب، وتحافظ عليها عند تعديل العنوان. تُستعاد روابط يوتيوب أيضًا من معرّف الفيديو عند غياب رابط المحتوى القديم.
- [ ] **٣. مؤجل بطلب المستخدم: حماية مشاهدة باني للمحتوى المدفوع.** مفتاح الرفع موصول، لكن مفتاح حماية التضمين غير موصول بكلاودفلير. يلزم تفعيل حماية التضمين في باني وربط مفتاحها عند استئناف العمل. لم يُغيّر التضمين أو إعدادات باني في هذه الجولة، ولم يثبت تسريب فيديو فعلي.
- [x] **٤. تم في الكود والاختبارات: إصلاح رفض دخول الطالب إلى صفحات المعلم.** يُوجّه الزائر إلى تسجيل الدخول والطالب إلى دوراته بدل خطأ خادم؛ تبقى الأعطال الحقيقية في استعلام الصلاحيات أخطاءً ولا تمنح وصولًا.
- [x] **٥. تم في الكود والاختبارات: ترجمة محرر الدروس واتجاهه.** واجهة مشتركة للمعلم والمدير تتبدّل مباشرة بين العربية والإنجليزية، وتشمل إنشاء وتحرير الدرس وحقول البث والرفع والحذف وحالات المشغّل. لا تُترجم عناوين الدروس التي كتبها المستخدم. هذا الإنجاز يخص المسارات الموثقة في التدقيق، ولا يُعد شهادة اكتمال ترجمة جميع شاشات المنصة.
- [ ] **٦. تحسين إتاحة النماذج والتباين.** ربط التسميات بالحقول وتحسين وضوح الروابط والتركيز في المظاهر المختلفة.
- [ ] **٧. تقسيم القوائم وتحسين البحث.** ترقيم الطلبات من الخادم، ومعالجة حد المئة دورة في الفهرس عند التوسع.
- [ ] **٨. تعزيز إعدادات الحماية.** رؤوس الأمان وحماية كلمات المرور المسرّبة وفق الخطة المتاحة، مع اختبار توافق المشغلات.
- [ ] **٩. تحسين استعلامات قاعدة البيانات.** معالجة تنبيهات الفهارس وسياسات الصفوف بناءً على القياس، مع إعادة اختبار العزل.
- [ ] **١٠. تحسين رفع الفيديو والتحكم بالتكلفة.** الحجم والحصص والمهل، وحالة المعالجة، وتنظيف الملفات المتروكة بأمان.

## ضوابط المتابعة

التحقق الحالي: ١٢٩ اختبارًا ناجحًا، وفحص الأنواع ناجح، وفحص جودة الشيفرة بلا أخطاء مع بقاء التحذيرات العشرة السابقة. تشمل الاختبارات حفظ عنوان الدرس دون تغيير الفيديو لجميع المزوّدين من إجراءات المعلم والمدير، واللغتين، ومنع الوصول. تُسجل أدلة التصفح والنشر بعد اكتمالها.

هذه قائمة إصلاحات وتحقيقات؛ الحالات غير المثبتة ليست أعطالًا مؤكدة. تبقى اختبارات البث والدفع الخارجية والأجهزة والمتصفحات والاستعادة مرحلة قبول مستقلة. لا تُشترى اشتراكات ولا تُنفّذ عمليات قد تسبب تكلفة تلقائيًا.

تُعلّم المهمة «تم» بعد تنفيذ الإصلاح والتحقق منه، مع بيان ما إذا كان وصل إلى الموقع المنشور. لا تغييرات في المدفوعات أو مخطط قاعدة البيانات أو حماية باني المؤجلة. المتبقي ستة بنود: ٣ و٦ و٧ و٨ و٩ و١٠.
